## Primeiro projeto

Análise de faturamento de produtos utilizando
Python, Pandas e Matplotlib.

### Objetivos
- Organizar dados de vendas.
- Calcular faturamento.
- Identificar produtos com maior receita.
- Criar visualizações de dados.

## Como executar

1. Criar um ambiente virtual Python.
2. Instalar as dependências com:
   `python -m pip install -r requirements.txt`
3. Abrir o notebook `primeira_analise.ipynb`.
4. Selecionar o kernel Python do ambiente virtual.
5. Executar as células.
